# 🚀 QUICK BUILD GUIDE - EGLA Tracker APK

## ⚡ Fastest Method (5 minutes)

### 1. Download Android Studio
- Go to: https://developer.android.com/studio
- Download and install Android Studio

### 2. Open Your Project
- Launch Android Studio
- Click "Open an Existing Project"
- Select folder: `C:\Users\leand\Desktop\test`
- Wait for Gradle sync (may take 2-3 minutes first time)

### 3. Build APK
- Menu: **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**
- Wait 3-5 minutes for build to complete
- Click "locate" to find your APK file

### 4. Install on Phone
- APK location: `app/build/outputs/apk/debug/app-debug.apk`
- Copy to your phone and install
- Enable "Unknown Sources" in phone settings if needed
